## 1. 顺序栈

存储是连续的指针数组。

- `data[0]` 是栈底，`data[top]` 是栈顶。
- 空栈时 `top == -1`。
- 元素类型是 `void *`，压的是已经存在的结点地址，不在栈里复制整棵树。
- 容量不够时按 2 倍扩容。`realloc` 失败时栈内容不变，入栈返回 -1。
- `stack_destroy` 只释放指针数组，不释放结点。结点由森林或二叉树负责释放。
- 本项目约定不压入空指针，因此出栈得到 `NULL` 就可以表示栈空。

入栈、出栈、读栈顶都是 \(O(1)\)。空间是当前栈深度，最坏 \(O(n)\)。后进先出是后面每一个算法的依据。

## 2. 路径回溯

每个目录结点有 `parent`。从目标沿父指针走到根，方向和要打印的路径相反。处理办法：

1. 从目标走到根，结点依次入栈。栈底将是目标，栈顶将是根。
2. 再依次弹出。弹出顺序是从根到目标。
3. 弹出的名字交给成员 1 的串，用 `/` 接成一条路径。

时间 \(O(h)\)，\(h\) 是结点深度，栈空间 \(O(h)\)。`parent` 只为了能向上走，不参加孩子兄弟的定义。孩子兄弟的两个指针由成员 4、成员 5 解释。

菜单 7 把每一次入栈、出栈都打印出来。示例文件的过程是：

1. 入栈 `习题.pdf`、`第3章`、`数据结构`、`计算机学院`
2. 出栈得到 `计算机学院/数据结构/第3章/习题.pdf`

只有一个根文件时，栈里只有它自己，路径就是文件名。

## 3. 先约定指针

成员 5 会完整讲转换。遍历时只需要记住：

- `firstChild` 是长子，对应二叉树左孩子
- `nextSibling` 是右兄弟，对应二叉树右孩子

下面用一棵固定的树说明序列。目录 A 的孩子依次是文件 B、文件 C：

- `A.firstChild = B`
- `B.nextSibling = C`
- 二叉树是 `A.lchild = B`，`B.rchild = C`

## 4. 孩子兄弟链表上的非递归先序

`cs_preorder` 把这条链当成二叉树来做先序。

1. 根入栈。
2. 弹出结点 `p` 并访问。
3. 若有右兄弟，先压 `nextSibling`。
4. 若有长子，再压 `firstChild`。

后压的长子位于栈顶，下一轮先处理长子，兄弟留到这棵子树结束之后。从森林第一棵根调用时，根的右兄弟链会把后面几棵树也走完。序列等于一般树的先根次序，也等于转换后二叉树的先序。时间 \(O(n)\)，栈最坏 \(O(n)\)。

`cs_tree_preorder` 只走一棵树：访问根之后，把孩子按相反顺序压栈，不压这棵树根自己的兄弟，因此不会跑到旁边那棵树。相反顺序靠一个临时栈完成：先按兄弟顺序压进临时栈，再弹到目标栈，下一个弹出的就是最左边的孩子。

A、B、C 的先序是 `A B C`。

## 5. 一般树的非递归后序

一般树后序是先从左到右处理每一棵子树，最后访问根。栈元素是一个帧，除了结点还有状态：

- 状态 0：刚入栈，孩子还没展开。
- 状态 1：孩子已经压到自己上面，下次轮到它就可以访问。

处理过程：

1. 根以状态 0 入栈。
2. 栈顶状态为 0 时，先改成 1，再把全部孩子按相反顺序压栈，每个孩子的状态都是 0。
3. 栈顶状态为 1 时，弹出并访问。

先改状态再压孩子。孩子都在它上面，孩子全部出栈之后，它重新成为栈顶，这时才访问。用下标保存栈顶位置，是因为继续入栈可能 `realloc`，原来指向栈内元素的指针会失效。

A、B、C 的一般树后序是 `B C A`。

森林的一般树后序是每棵树各自做一次，树与树之间按根的兄弟次序。不能把整片森林直接做成一次二叉树后序，那会得到另一个序列。

## 6. 二叉树非递归先序

`bi_preorder`：弹出并访问后，先压右孩子，再压左孩子。栈顶是左孩子。入栈习惯和孩子兄弟先序相同。A、B、C 的结果仍是 `A B C`。

## 7. 二叉树非递归中序

`bi_inorder`：

1. 沿左链一直入栈，直到空。
2. 弹出并访问。
3. 转向右孩子，回到第 1 步。

在转换来的二叉树上，右孩子是兄弟。访问完 B 之后会先去 B 的右孩子 C，然后才回到根 A。中序是 `B C A`。中序用来核对“右指针表示兄弟”，不是用来按目录层次列出文件。

## 8. 二叉树非递归后序

`bi_postorder` 用一个 `last` 记住上一次访问的结点。

1. 沿左链入栈。
2. 看栈顶。若右孩子存在，并且还不是 `last`，说明右子树没走完，转向右孩子，当前结点留在栈里。
3. 否则左右都处理完了，弹出并访问，把 `last` 更新为它。

A、B、C 的二叉树后序是 `C B A`。C 被看成 B 的右子树，所以先访问 C，再访问 B，最后访问 A。一般树后序是 `B C A`。两个序列不同，原因在指针含义，详细对照由成员 5 讲。本成员要能在纸上把栈的变化写出来。

三种非递归遍历的时间都是 \(O(n)\)。栈空间最坏 \(O(n)\)，例如树退化成一条链；树比较平衡时深度是 \(O(h)\)。

## 9. 递归版本的用途

`bi_preorder_rec`、`bi_inorder_rec`、`bi_postorder_rec` 不作为菜单上的主算法。它们和栈版本收集出的名字序列必须一致，用来证明非递归没有漏结点，也没有重复访问。菜单 8 会打印“非递归先序与递归先序是否一致”。
