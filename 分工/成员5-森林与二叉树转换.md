## 1. 为什么要做一次显式转换

孩子兄弟链表本身就可以当成二叉树读：左孩子是长子，右孩子是右兄弟。若只是换一种口头说法，屏幕上仍然只有一套结点，无法并排对照，也无法在转回去之后和原树比较。

本项目把每个结点复制一份，得到另一棵 `BiNode` 二叉树。原森林继续按树来用，新二叉树按左右孩子来用。复制的时间是 \(O(n)\)，新结点的空间是 \(O(n)\)，\(n\) 为结点数。直接在原树上遍历则不必复制，额外空间只有成员 3 的遍历栈，深度为 \(O(h)\)。这就是题目要求的对比：直接在孩子兄弟树上操作，和先转为二叉树再遍历。

## 2. 对应关系

教材中树转二叉树的过程是：兄弟之间连线，每个结点只保留到第一个孩子的边，再把图形顺时针转大约 45 度。落到指针上就是：

- 二叉树左孩子 = `firstChild` = 长子
- 二叉树右孩子 = `nextSibling` = 右兄弟

森林有多棵树时，下一棵树是当前根的右兄弟。从第一棵根看，整片森林已经是一棵二叉树，根的右链就是其余的树。空森林转换成空指针。

固定例子：目录 A 的孩子依次是 B、C。

- 树上：`A.firstChild = B`，`B.nextSibling = C`
- 二叉树上：`A.lchild = B`，`B.rchild = C`
- A 没有右兄弟，所以 `A.rchild` 为空
- B、C 都没有孩子，所以它们的左孩子为空

括号表示是 `A(B(#, C), #)`。没有孩子的叶子可以不印括号。空孩子印成 `#`。菜单 9 还会逐个结点打印“左孩子/长子”和“右孩子/右兄弟”。

## 3. 森林转到二叉树

`cs_to_bi_node` 对每个结点：

1. 复制名字、类型、大小、扩展名，得到新的二叉树结点。
2. 左孩子设为“原结点长子”递归转换的结果。
3. 右孩子设为“原结点右兄弟”递归转换的结果。

递归的顺序就是先处理长子那一支，再处理兄弟链。任一子转换因为内存不足失败时，把已经建好的部分二叉树释放掉，不把半成品交出去。`forest_to_bi` 从 `firstRoot` 开始调用。它只读原结点，不改 `firstChild`、`nextSibling` 和 `parent`。

时间 \(O(n)\)，每个结点访问一次并新建一个结点。递归深度最坏 \(O(n)\)，例如树退化成一条长子链或一条兄弟链。

## 4. 二叉树转回森林

`bi_to_cs_node(b, parent)` 的 `parent` 是新结点应该指向的父亲。

1. 复制数据，得到孩子兄弟结点。
2. 新结点的 `parent` 设为参数 `parent`。
3. 左孩子递归转成长子。长子的父亲参数传入新结点自己。
4. 右孩子递归转成右兄弟。右兄弟的父亲参数仍然传入原来的 `parent`，而不是新结点自己。

第 4 步是转回时最容易讲错的地方。右孩子表示的是兄弟，兄弟和自己拥有同一个父亲。若把右孩子的父亲设成自己，B 的兄弟 C 会变成 B 的孩子，树就错了。

对整棵二叉树调用时，根的父亲传入 `NULL`。根的右链转回去后，那些结点的父亲也是 `NULL`，它们重新成为森林中的各棵树根。

## 5. 可逆验证

转换菜单做三件事，并且都发生在一份副本上：

1. 打印原森林。
2. 转成二叉树，打印括号表示和左右孩子对照表。
3. 再转回一棵新森林，和原森林比较。

`forest_equal` 比较名字、类型、大小、扩展名，以及长子链和兄弟链是否递归相同。它不比较指针地址，因为副本的地址必然不同。

`forest_parents_ok` 检查每棵树根的 `parent` 是否为空，以及每个孩子的 `parent` 是否指回父亲。兄弟之间的父亲必须相同。

验证结束后释放二叉树和转回来的森林。原森林的结点数、原路径必须保持原样。示例森林转换前后都是 14 个结点。空森林转成空二叉树，再转回仍是空森林。

## 6. 四种序列分别说明什么

仍用 A 的孩子 B、C。遍历算法由成员 3 执行，本成员负责解释结果。

| 遍历 | 序列 | 说明 |
|---|---|---|
| 一般树先序，也是孩子兄弟先序 | A B C | 先根，再从左到右各子树 |
| 二叉树先序 | A B C | 与上一行相同，因为左=长子、右=右兄弟 |
| 二叉树中序 | B C A | C 出现在 B 和 A 之间，因为 C 是 B 的右孩子 |
| 一般树后序 | B C A | 先子树 B，再子树 C，最后根 A |
| 二叉树后序 | C B A | 先左子树，再右子树，最后根。C 在 B 的右子树里 |

先序相同，说明直接遍历和先转换再遍历看到的是同一套父子兄弟关系。中序用来核对右指针。两种后序不同，说明“右孩子”不是第二棵子树。只有完全没有兄弟、退化成一条长子链时，两种后序才会碰巧一样。答辩时要主动说出这个差别，并在菜单 9 的示例输出里指出来。

直接遍历的额外空间是栈的深度 \(O(h)\)。先转换再遍历要先使用 \(O(n)\) 时间和 \(O(n)\) 空间复制结点，遍历本身仍是 \(O(n)\)。功能上先序结果一样，代价上直接走更省。
